# Quickshell Cheat Sheet

## Launcher
| Atalho | Ação |
|---|---|
| `Super + Space` | Abrir Launcher / Overview |
| `Super + /` | Abrir Cheat Sheet |
| `Alt` | Pressionar para ver pré-visualização de arquivos/apps |
| `Tab` | Alternar Modo / Ações de Contexto |
| `Down` / `Up` | Navegar nos resultados |

## Dock & Window Management
| Atalho | Ação |
|---|---|
| `Super + Alt + D` | Navegação pelo teclado na Dock |
| `Hotcorner Superior Esquerdo` | Abrir Overview (Todas as Workspaces) |
| `Hotcorner Superior Direito` | Expose Mode (Trazer janelas para a atual) |
| `Hotcorner Inferior Esquerdo` | Abrir Launcher |
| `Hotcorner Inferior Direito` | Alternar Special Workspace correspondente |

## Painéis e Widgets
| Atalho | Ação |
|---|---|
| `Scroll (Roda do Mouse)` | Áudio: Esq=Mic, Dir=Saída / Bateria: Esq=Perfil, Dir=Brilho |
| `Clique na Bateria` | Alternar modos de desempenho |
| `Clique na Rede` | Abrir configurações de Rede |
